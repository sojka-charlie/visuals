# visuals
 [https://sojka-charlie.github.io/visuals/](https://sojka-charlie.github.io/visuals/)
 
Portfolio repository for interactions and UI tools.

## Repository Contents

This repository contains:
- Portfolio content and documentation
- Screenshot capture automation for interactive figures
- Build and deployment configuration

## Development

### Capturing Figure Screenshots

See [CAPTURE_README.md](./CAPTURE_README.md) for instructions on capturing screenshots and videos of interactive figures.

```bash
# Quick start
npm run setup    # Install dependencies and browsers
npm run capture  # Capture all figures
```

## Deployment

The site is automatically deployed to GitHub Pages via GitHub Actions when changes are pushed to the main branch.
